## Introduction

A Typescript package for general UTxO selection, providing an all required types of `@rosen-bridge/abstract-box-selection`.

## Installation

npm:

```sh
npm i @rosen-bridge/selection-types
```

yarn:

```sh
yarn add @rosen-bridge/selection-types
```
